E-Commerce Sales Analysis Dashboard

Built an end-to-end E-Commerce analytics workflow using MySQL and Power BI, transforming raw sales data into a structured analytical model and a multi-page interactive report.

  • Imported, cleaned, and transformed 1,900+ sales records using MySQL Workbench, addressing nulls, malformed rows, and inconsistent data types.
  • Designed a star schema with one fact table and four dimensions: customer, product, region, and date.
  • Created 25+ DAX measures through TMDL, including profit margin, month-over-month growth, YTD sales, repeat-customer rate, loss-making orders, and delivery days.
  • Built a 5-page interactive Power BI report covering Overview, Products, Customers, Regions, and Shipping & Discount.
